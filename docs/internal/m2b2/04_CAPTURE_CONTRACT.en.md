# M2-B2 — Attempt capture and provenance contract (EN)

**Design only:** `data/planning/attempt_capture.empty.json` deliberately uses `record_kind=EMPTY_TEMPLATE_NOT_A_RUN`, `execution_status=NOT_RUN`, with all actual capture values null. There is no real model result. `tools/attempt_contract.mjs` is an in-memory pure function module without fetch, SDK or authentication support.

| Future field                                                          | Required interpretation                                                                                                                                                          |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `record_kind`, `evidence_origin`                                      | `CAPTURED_ATTEMPT`; label `AUTHORIZED_CAPTURE` only following live approval, or `SYNTHETIC_TEST` for test inputs. Never relabel synthetic results as real.                       |
| `scenario_id`, `attempt_id`                                           | Stable scenario and unique attempt identifiers; each retry becomes a distinct recorded attempt.                                                                                  |
| `application_commit`                                                  | Full 40-character Git commit of the actual running application, not assumed from a template.                                                                                     |
| `request`, `request_sha256`                                           | Request `source`/`target` locale codes, `uiLocale`, topic, level, count and mode. Compute SHA256 over canonicalized JSON keys. A request hash is **not** a provider prompt hash. |
| `attempt_started_utc`, `attempt_finished_utc`, `elapsed_ms_monotonic` | ISO 8601 UTC provenance and monotonic elapsed milliseconds; do not rely on wall-clock subtraction for latency.                                                                   |
| `transport_outcome`, `http_status`, `error_code`                      | Distinguish HTTP responses from timeout/network exceptions. Do not fabricate HTTP status when none was received.                                                                 |
| `response.pairs`, `requestedCount`, `returnedCount`, `partial`        | Only on HTTP 200; pair count equals returnedCount and cannot exceed request count; `partial=(returnedCount<count)`. Failures have `response=null`.                               |
| `isFallback`, `cacheHit`                                              | Preserve API-provided booleans on success. Separate fallback and cache delivery from primary model quality.                                                                      |
| `provider.model_name`, `model_revision`, `model_identity_status`      | May be `UNKNOWN_NOT_EVALUATED`; use `VERIFIED` only after real identity/revision evidence exists.                                                                                |
| `prompt_hash_sha256`, `model_config_hash_sha256`                      | Null if unavailable. A prompt hash is not a request hash; exclude potentially sensitive raw prompts from shared evidence.                                                        |
| `verified_cost_usd`, token usage                                      | Null when not verifiably measured; request quotas are not USD budget caps.                                                                                                       |
| `human_review_status`, `semantic_scores`                              | Captured-but-unreviewed samples remain `NOT_EVALUATED` and null; ratings must come from independent real humans.                                                                 |

Only when actual pairs exist can the system assign `sample_id=(attempt_id,pair_index)` and route them to blinded human assessment. No attempts means no semantic accuracy rate—not 0% and not 100%.

`tools/attempt_contract.mjs` exports `validateCapturedAttempt()` and `summarizeAttempts()` for synthetic contract testing. Delivery denominators include HTTP 429/503, timeout and network failures. It does not collect real responses, call AI, or infer independent model executions from API delivery records. Any future executable collector requires separate owner authorization for model, budget, sandbox, code changes and evidence handling.
